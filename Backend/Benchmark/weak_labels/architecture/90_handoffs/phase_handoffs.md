# Phase handoffs

```text
Layer1 → Phase A
canonical history + manifest

Phase A → B1
candidate evidence + Q threshold candidates + continuity diagnostics

B1 → B2
Q×K geometry + fold/support audits + compatibility candidates

B2 → Phase C
one frozen semantic contract

Phase C → Evaluation
Point/Temporal Assignments + provenance

Dataset Views → Evaluation
feature artifacts + feature eligibility

Evaluation → Model Suite
train-ready dataset and fold projection
```

Mỗi handoff chỉ truyền artifact mà phase sau thực sự sử dụng. Audit artifact
được giữ để review/provenance, không tự biến thành bước xử lý mới.
