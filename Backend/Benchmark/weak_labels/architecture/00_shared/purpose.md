# Phần chung — Purpose và responsibility

## Weak Labels làm gì?

Weak Labels nhận dữ liệu canonical đã được Layer1 chuẩn hóa và tạo ra các
semantic target có bằng chứng truy ngược được.

```text
Layer1 canonical
  → audit và candidate evidence
  → review/freeze semantic contract
  → native Point/Temporal label assignments
```

Weak Labels không chịu trách nhiệm cho feature Dataset Views, model, training,
feature eligibility cuối cùng hoặc matched train-ready cohort.

## Ba loại output

### Core result

```text
Phase A: candidate evidence
B1: Q×K candidate geometry/decision pack
B2: frozen semantic contract
Phase C: Point/Temporal assignments
```

### Support result

```text
integrity, continuity, fold support, distribution,
provenance, hash, compatibility
```

Support result không tự trở thành nhãn hoặc semantic decision.

### Handoff result

```text
Phase A → B1: candidate evidence + thresholds
B1 → B2: decision pack
B2 → C: frozen semantic contract
C → Evaluation: label assignments
```
