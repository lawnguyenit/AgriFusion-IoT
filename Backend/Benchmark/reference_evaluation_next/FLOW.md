# Implemented extension flow

protocol.json → journal protocol/source/environment lock → unit receipts/READY.
All prior v1/P2 source and evidence remain read-only.

P3: mechanisms.trace → strictly causal six-schedule probabilities → matched
mask placement → public EvaluationSegment → v1 comparison owner → bounds-only
pool choices → audit-only true losses → R0 primary witnesses/recheck → case
artifacts → discovery and heldout contrasts → explicit P3 gate.

P4: P3 gate → source235 acquisition/checksum → strict minute/hour canonical data
→ folds train-only threshold and calendar/gap segmentation → FitBudget guarded
v1 candidates → verified fit registry → fixed causal forecast bundles → independent
reference roles → v1 all-pairs bounds/points → bounds-only choices and selection
decisions → downstream audit outcomes → later assessment and baseline report.
No fit depends on evaluator, reference mask, selection or assessment outcome.

Each new reference cell checks fixed prediction/cohort fingerprints. Complete
reference must collapse all pair intervals. Audit risk differences and regret
must lie within computed pair/regret bounds. Only predeclared subset receives
full primary witnesses. Reference-MCAR HT uses actual operand inclusion chances;
block HT is not generated. High/low I contrasts retain same p/cohort and missing
count. Support flags flow into final tables and primary interpretation.

Persistence is journal/table helpers; numeric/source/fit owners remain separate.
Completed manifest bytes are immutable, and failed operations retain receipts.
Reporting joins only already-generated outputs and never changes training units.
P5 disposition and P6 document/figures live in a distinct final delivery package.
